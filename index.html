Pendahuluan & Alat

Kabel LAN (Local Area Network) / Ethernet adalah media transmisi fisik berupa kabel yang digunakan untuk menghubungkan berbagai perangkat jaringan (seperti komputer, router, dan switch) dalam area geografis yang terbatas. Fungsinya adalah mentransfer data antar perangkat dengan kecepatan tinggi dan latensi rendah.

Alat-Alat yang Digunakan:

Kabel UTP (Cat5e/Cat6)

Kabel pasangan berpilin sebagai media penghantar data.

Konektor RJ-45

Konektor standar di kedua ujung kabel LAN.

Tang Crimp (Crimping Tool)

Alat untuk memotong, mengupas, dan mengunci konektor RJ-45.

LAN Tester

Alat untuk menguji keterhubungan dan urutan kabel UTP.

Cara Pembuatan Kabel LAN (Tipe Crossover)

Untuk menghubungkan dua perangkat sejenis (seperti Laptop ke Laptop secara langsung tanpa Switch), kita umumnya menggunakan susunan **Kabel Crossover** (Ujung A = Standard Straight T568A, Ujung B = T568B, atau susunan standar Cross).

Urutan Warna Kabel:

Ujung A (Standard T568A): Putih Hijau - Hijau - Putih Orange - Biru - Putih Biru - Orange - Putih Cokelat - Cokelat

Ujung B (Standard T568B): Putih Orange - Orange - Putih Hijau - Biru - Putih Biru - Hijau - Putih Cokelat - Cokelat

Langkah Pembuatan:

  1. Kupas jaket luar kabel UTP sepanjang ± 2 cm menggunakan tang crimp.
  2. Luruskan dan pisahkan pilinan kawat di dalamnya.
  3. Urutkan warna kawat sesuai dengan standar Ujung A dan Ujung B di atas.
  4. Ratakan ujung kawat dengan memotongnya lurus secara rata.
  5. Masukkan kawat ke dalam konektor RJ-45 sampai ke ujung konektor.
  6. Press konektor RJ-45 menggunakan tang crimp hingga mengunci (terdengar bunyi klik).
  7. Tes kabel menggunakan LAN Tester. Jika indikator lampu menyala sesuai urutan pasangannya, kabel siap digunakan.

Menghubungkan 2 Laptop & Sharing File

1. Pengaturan IP Address (IPv4)

Tancapkan kedua ujung kabel LAN ke port Ethernet masing-masing laptop. Atur IP secara manual:

  • Buka Control Panel > Network and Sharing Center > Change adapter settings.
  • Klik kanan pada Ethernet > Pilih Properties > Klik 2x pada Internet Protocol Version 4 (TCP/IPv4).
  • Laptop 1: IP Address: 192.168.1.1 | Subnet Mask: 255.255.255.0
  • Laptop 2: IP Address: 192.168.1.2 | Subnet Mask: 255.255.255.0

2. Pengecekan Keterhubungan (PING Test)

Pengecekan ini digunakan untuk memastikan jaringan fisik dan logis antar kedua laptop sudah terhubung dengan baik.

  • Buka Command Prompt (CMD) di Laptop 1.
  • Ketikkan perintah berikut untuk mengecek ke Laptop 2:
ping 192.168.1.2

Jika mendapat balasan Reply from 192.168.1.2: bytes=32 time<1ms TTL=128, maka kedua laptop sudah berhasil terhubung.

3. Cara Transfer File (File Sharing)

  1. Pastikan Password Protected Sharing dimatikan di Advanced sharing settings Control Panel.
  2. Pilih folder yang ingin dibagikan di Laptop 1, klik kanan > Properties.
  3. Masuk ke tab Sharing > Klik tombol Share...
  4. Pilih Everyone, tambahkan (Add), lalu set Permission Level menjadi Read/Write, klik Share.
  5. Pada Laptop 2, buka File Explorer, ketik alamat IP Laptop 1 di address bar: \\192.168.1.1 lalu tekan Enter.
  6. Folder yang di-share sekarang dapat diakses dan diunduh oleh Laptop 2.
